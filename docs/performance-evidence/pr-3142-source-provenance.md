# Historical performance sources for PR #3142

Current performance work uses [standard tooling](../../.github/benchmarks/STANDARD-TOOLS.md): BenchmarkDotNet for microbenchmarks and original exports, with dotnet-counters/dotnet-trace for separate profiling runs. BenchmarkDotNet controls warmup; verify elapsed workload warmup in its full JSON before claiming steady-state acceptance.

Historical reports and raw measurements remain unchanged. Their source references describe the original experiments, not maintained tooling or current-head acceptance. The source snapshots and custom scripts are retained at [the original commit](https://github.com/thomhurst/Dekaf/tree/49ef6ef3d590f3b6da50483eeafab5b7ca307f68/docs/performance-evidence). Relative source references in those historical reports refer to that tree.
