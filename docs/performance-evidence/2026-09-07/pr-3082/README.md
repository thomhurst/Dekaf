# PR #3082: performance evidence, 2026-09-07

Large binary-key dispatch improves approximately 15–20% in the fixed CPU/JIT comparison. Allocation is unchanged; full-content hashing still costs more than the incorrect reference-equality baseline.

**Performance acceptance: BLOCKED; merge remains blocked.** The GitHub `agent/performance-gate` status uses `failure` because legacy statuses have no terminal inconclusive state that also blocks merging. It is not a claim that every observed difference is a proven regression. CPU/message, p50/p99/max latency and stability are not all established; no protected-metric tradeoff is accepted.

80 unit cases pass on each of net10.0 and net8.0; 6 Kafka integration cases pass on net10.0. The product patch matches the previously validated patch byte for byte.
